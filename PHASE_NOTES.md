# R.O.B.I.N Phase 1 Notes

R.O.B.I.N stands for Real-time Oversight of Breaches, Incidents, & Networks.

## Phase 1 Goal
Build a working local network monitoring platform with scanning, risk tracking, alerting, dashboard visibility, and manual response controls.

## Completed Features
- Network device discovery
- Device history tracking
- LOW / HIGH / CRITICAL risk levels
- Last seen timestamps
- Telegram alerts
- Flask dashboard
- Ban / Unban controls
- JSON-based data storage
- Modular Python structure
- Environment variable support

## Technologies Used
- Python
- Flask
- Telegram Bot API
- Linux
- iptables
- JSON
- HTML/CSS

## Current Status
Phase 1 is complete as a working prototype focused on visibility, alerting, and basic response.

## Next Phase
Phase 2 will focus on smarter detection, better device fingerprinting, threat intelligence, and improved security hardening.
